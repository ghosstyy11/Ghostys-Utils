Ghosty's Utils
=====
This unity package contains lots of tools to help you with Gorilla Tag Virtual Stump mapping.

## How To Install
First, download the GhostysUtils.dll from the [Releases](github.com/lewis6777/Ghostys-Utils/releases/latest) tab.
Then, create a folder called "Editor" in your unity project's Assets folder.
Finally, put the GhostysUtils.dll into that folder.

## Tools
Here, I'll explain what each window does and how to use it.
### Settings
This window contains some links to useful places, as well as some basic settings.

#### Startup
##### Open Luau Code editor on startup
This attempts to open the code editor you use to code custom gamemodes in, opening it into the Luau folder of this project. This definitely works with VS Code, but I'm not too sure on what other applications work with this.
It has the same function as *Other/Open Luau code editor*.

#### Export
##### Upload to Mod.io on map export
With this ticked, the Uploader tab will automatically be run after you export a map.
**You must set up the Uploader window to use this!**
##### Ask before uploading
This option requires the previous one to be enabled to actually do anything.
If ticked, a popup will appear after exporting a map, asking if you wish to upload it or not.
